# Hero's Lib

Hero's Lib is a library for a few of my mods. But it could work with you if you want to make an addon for **Hero's Level** and want
to make a compatible tab

## Installation

Hero's Lib is built for NeoForge 1.21.1. It requires [Cloth Config](https://modrinth.com/mod/cloth-config/version/15.0.140+neoforge).
